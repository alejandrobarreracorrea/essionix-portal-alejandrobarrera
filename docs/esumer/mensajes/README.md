# Mensajes de WhatsApp enviados — Esumer

Archivo de los mensajes que se envían a los grupos por WhatsApp: **anuncios** (antes de
clase, con Meet + plan) y **recaps** (después, con la grabación + repaso). Uno por
grupo+clase. Ver el flujo completo en [`../FLUJO.md`](../FLUJO.md).

Convención de nombre: `mensajes/RED-0N/AAAA-MM-DD-<tipo>-clase-0M.md`
(`tipo` = `anuncio` | `recap`).
