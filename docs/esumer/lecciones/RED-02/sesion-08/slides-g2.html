🧪 PASO 1 Instala Docker en tu EC2

Docker en Amazon Linux

  • sudo dnf install -y dockerinstala Docker
  • sudo systemctl enable --now dockerlo enciende (y arranca solo al reiniciar)
  • sudo usermod -aG docker ec2-userte da permiso de usar Docker sin sudo
  • newgrp dockeraplica el permiso ya, sin salir
  • docker run --rm hello-worldprueba: un contenedor que saluda y se borra

Checkpoint ✅ al chat: el mensaje Hello from Docker! Si sale permission denied, corre newgrp docker otra vez.

🧪 PASO 2–3 Tres sitios, tres contenedores

Crea los sitios A, B y C y enciéndelos

  • Paso 2 · el for crea 3 carpetas con un index.html de colorA rojo · B verde · C azul
  • docker network create red-webuna red privada para que se encuentren por nombre
  • Paso 3 · docker run -d --name web-A …un NGINX liviano (nginx:alpine) por sitio, con su carpeta adentro (-v)
  • docker ps¿están los 3 corriendo?

Los comandos completos para copiar y pegar te los paso por el chat. Checkpoint ✅: pantallazo de docker ps con web-A, web-B y web-C.

🧪 PASO 4 El balanceador de carga

Un NGINX que reparte las visitas

  • upstream sitios { … }la lista de contenedores a los que reparte
  • zone sitios 64k;que todos los procesos de NGINX compartan el turno (sin esto, siempre responde A)
  • proxy_pass http://sitios;"lo que llegue, pásalo a uno de la lista"
  • sudo systemctl stop nginxapaga el NGINX viejo: el puerto 80 ahora es del balanceador
  • -p 80:80el único contenedor con puerta a la calle

Checkpoint ✅: abre http://tu-IP-pública y recarga con Ctrl+F5 varias veces: ¿cambia de color?

🧪 PASO 5 Prueba de fuego

Mira el reparto… y tumba un contenedor

  • for i in 1 2 3 4 5 6; do curl -s localhost | grep -o "Sitio ."; done6 visitas seguidas: ¿se reparten?
  • docker stop web-Bapaga un sitio a propósito
  • repite las 6 visitas¿la web sigue viva sin B?
  • docker start web-BB vuelve al reparto en ~10 s (si no: docker restart balanceador)
  • docker logs balanceador --tail 5el registro de quién atendió

Checkpoint ✅ al chat: la salida del for antes y después de tumbar web-B.

📋 CHULETA Los comandos de Docker que usaste hoy

Tu chuleta de Docker

  • docker run -d --name X imagencrea y enciende un contenedor (-d = en segundo plano)
  • docker ps / docker ps -alos que están corriendo / todos
  • docker stop X · docker start Xapagar y encender
  • docker logs Xqué ha pasado dentro del contenedor
  • docker exec -it X shentrar al contenedor (como SSH, pero a la habitación)
  • docker imageslos moldes descargados (nginx:alpine pesa ~20 MB)
  • docker rm -f Xborrar un contenedor
  • -p 80:80 · -v carpeta:ruta · --network redabrir puerto · montar una carpeta · conectar a una red
✅ CIERRE Deja la casa en orden

Antes de irte: vuelve a tu web de siempre

  • Borra los contenedores: docker rm -f balanceador web-A web-B web-C
  • Borra la red: docker network rm red-web
  • Enciende tu NGINX de siempre: sudo systemctl enable --now nginx → tu web vuelve a la IP pública
  • docker ps -a vacío y curl -I localhost → 200 OK
  • ¿No lo vas a usar más hoy? Stop a la instancia — capa gratuita cuidada 💵
