01
la nube, idea 1 de 5

Pagas por lo que consumes

// como la luz de tu casa

No compras la planta eléctrica: pagas los kilovatios que usas. Nadie compra un servidor de USD 10.000 “por si acaso”.

02
la nube, idea 2 de 5

Tu app vive cerca del usuario

// como las sucursales de un banco

Regiones y zonas: si una sede se cae, otra sigue. AWS tiene ~35 regiones repartidas por el mundo.

03
la nube, idea 3 de 5

Seguridad: cada quien su parte

// como el edificio y tu apartamento

AWS asegura el edificio; tú, lo que hay dentro: tus datos, tus llaves, tus permisos. El error más caro de quien empieza vive en tu mitad.

04
la nube, idea 4 de 5

Serverless: sin servidores tuyos

// como un taxi, no un carro propio

El código corre solo cuando llega una petición y pagas por milisegundo. Hay servidores, pero no son tu problema.

05
la nube, idea 5 de 5

La nube ahora piensa

// con Amazon Bedrock

Invocas modelos como Claude o Nova con una llamada de API y pagas por token. Sin entrenar nada, sin GPUs propias.
