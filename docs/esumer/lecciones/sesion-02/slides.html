LAB 1 Ubicarse en el terreno

¿Dónde estoy? ¿Qué hay aquí?

$ pwd        # ¿en qué carpeta estoy?

$ ls         # ¿qué hay aquí? (tu README debería estar)

$ ls -la     # …¿y lo escondido? (ojo con .git — LOS PLANOS)

$ cd /tmp && pwd  # moverse a otra carpeta

$ cd ~       # volver a casa

$ clear      # limpiar la pantalla

Mini-reto al chat: dentro de su repo hay una carpeta oculta. ¿Cómo se llama?

LAB 2 Construir

Las primeras piezas de la casa

$ mkdir planos materiales          # crear carpetas

$ echo "Somos [tu empresa]" > materiales/lema.txt

$ cat materiales/lema.txt          # leerlo

$ nano materiales/lema.txt         # editar (Ctrl+O guarda · Ctrl+X sale)

$ cp materiales/lema.txt lema-copia.txt # copiar

$ mv lema-copia.txt planos/         # mover

$ rm planos/lema-copia.txt         # borrar — SIN papelera ⚠️

rm no perdona. Antes de borrar: respirar, leer dos veces. En una casa real, tumbar la pared equivocada sale caro.

LAB 3 Parada 3 · los planos

Preséntate con el arquitecto: configura Git

$ git config --global user.name "Tu Nombre"

$ git config --global user.email "tu@correo.com"  # el MISMO de GitHub

$ git status       # ¿qué cambió en la casa desde el último plano?

Git es el arquitecto que anota TODO: quién cambió qué, cuándo y por qué. Por eso necesita tu nombre. En Codespaces la conexión con GitHub ya viene lista — en un computador normal habría un paso más (lo veremos).

EL RITO DE PASO tu primer push

Del cemento al plano oficial — en 3 comandos

$ git add .                     # "arquitecto: mira esto"

$ git commit -m "Primeras piezas de la casa" # "fírmalo en el plano"

$ git push                      # "archívalo en la oficina"

  • Ahora: abran github.com/[usuario]/bitacora-[empresa] en otra pestaña…
  • …y ahí están: planos/ y materiales/, creados desde la terminal, publicados en internet

Eso que sintieron es el flujo que usan los equipos de tecnología del planeta entero. Ya son parte. 📐

🔐 Minuto de seguridad #1 · nueva tradición

Un repo público es una casa con ventanas

  • Todo lo que suben, lo ve internet ENTEROY lo que se publicó, aunque se borre, alguien pudo copiarlo⚠️
  • Regla 1 · JAMÁS subir contraseñas, llaves o tokensNi "un momentico" — hay bots escaneando GitHub 24/7 buscando exactamente eso01
  • Regla 2 · Datos personales tampocoCédulas, teléfonos, correos de otros: nunca al repo02
