LAB 1 Ubicarse

¿Dónde estoy? ¿Qué hay aquí?

$ pwd        # ¿en qué carpeta estoy?

$ ls         # ¿qué hay aquí?

$ ls -la     # …¿y lo escondido, con detalles?

$ cd /tmp    # moverse a otra carpeta

$ cd ~       # volver a casa

$ clear      # limpiar la pantalla

Mini-reto al chat: ¿qué devuelve pwd recién entras a CloudShell?

LAB 2 Crear

Construye la estructura de tu empresa

$ mkdir mi-empresa          # crear carpeta

$ cd mi-empresa && mkdir web datos redes

$ touch web/index.html       # crear archivo vacío

$ echo "Somos [empresa]" > lema.txt  # crear CON contenido

$ cat lema.txt             # leerlo

$ nano lema.txt            # editarlo (Ctrl+O guarda, Ctrl+X sale)

LAB 3 Mover, copiar… y el comando que no perdona

cp · mv · rm

$ cp lema.txt lema-backup.txt   # copiar

$ mv lema.txt web/            # mover

$ mv lema-backup.txt el-lema.txt # …también renombra

$ rm el-lema.txt            # borrar — SIN preguntar, SIN papelera

rm no perdona. En este curso, antes de borrar: respirar, leer dos veces, copiar primero. Lo reversible se hace tranquilo; lo irreversible, con cuidado — recuerden esto cuando lleguemos a producción.

LAB 4 Inspeccionar y encadenar

Los superpoderes

$ history                 # todo lo que has escrito

$ man ls                  # el manual (q para salir)

$ history | grep mkdir      # el tubo | conecta comandos

$ ls web/ && echo "existe"   # && = "si funcionó, entonces…"

El tubo | es la idea más poderosa de Unix: comandos pequeños que se combinan. La van a usar todo el semestre.
